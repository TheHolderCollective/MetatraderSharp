## MetatraderSharp

MetatraderSharp is wrapper library which aims to simplify the use of the MTsocketAPI.

## Project Status

[27-Aug-2026] - Under review and testing.

## Usage Requirements
Successful usage of the MetatraderSharp library requires:
- Metatrader 4/Metratrader 5 to be installed 
- a version of the MTsocketAPI installed in your Metatrader

For more information on how to install the MTsocketAPI please consult: https://www.mtsocketapi.com/

## Usage Examples

For examples on how to use the library please consult the cookbook which can be found in this repository:

https://github.com/TheHolderCollective/MetatraderSharpCookbook

I have no connection or affiliation with MTsocketAPI. This library is purely a labour of love which arose from my need to have an easy way to pull data from my MetaTrader terminals.
